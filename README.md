# GROUNDWORK Studio — Kotagiri Spatial & Earthwork Tool

Interactive architectural program bubble diagram, 3D site massing, cut/fill earthwork calculator, and live clipping-plane section tool for **Groundwork** (Artists' Residency for the Keystone Foundation in Kotagiri, The Nilgiris, Tamil Nadu).

## Live App
- **GitHub Pages:** https://atalayfersiz.github.io/MassingTool/
- **Offline / Local:** Download or clone this folder and double-click `index.html`.

## Features
- **True-Scale Plan Bubble Diagram (`2`):** Area-locked rectangular bubbles (`W × D = Target Area / Floors`), multi-floor splitting, contour rotation, grouping (`G` / `Shift+G`), stacking, relevance outline grading, and proximity keyword merging.
- **Roombook Keyword Filtering:** 42 keywords extracted from the highlighted Roombook PDF, individually toggleable (`Include / Exclude`) with live relevance re-scoring.
- **3D Site & Earthwork (`3`):** Real Kotagiri terrain mesh (`6,390 m²` plot boundary, `28.9 m` slope drop, contours, roads, waterways, surrounding context buildings, vegetation), XYZ transform gizmo, and terrain-conforming Cut (`m³`) & Fill (`m³`) soil meshes.
- **Rhino-Style Clipping Planes & Live Section (`4` / `1` Split):** Synchronized 2D Section showing slope profile, Cut/Fill soil hatches & `m³` volumes, and interactive top-edge height handles (`3.0 m` default).
- **Dimension Tool (`D`):** Distance, `ΔZ`, and slope `%` measurements across Plan, 3D, and Section.
- **Dark Mode (`M`) & Keyboard Shortcuts (`?`):** Minimal warm-graphite theme, `.json` save/load, PNG snapshots, and vector Plan/Section SVG exports.
